# Lab 2 — Jira Bug Tracking

This folder follows the Lab 2 example layout and uses the Lab 1 **Hyperlocal
Courier Dispatch & Tracking Engine** as the project under test.

## Deliverables

- `Bug_Reports.md` — five sample bug records with reproduction steps,
  expected/actual results, severity, priority, and status.
- `Bug_Board.png` — Jira-style Kanban board preview.
- `Bug_Tracking_1_Create_Project.gif` — project creation flow preview.
- `Bug_Tracking_2_Log_Bug.gif` — bug issue creation flow preview.
- `Bug_Tracking_3_Assign_Comment_Resolve.gif` — assignment, comment, and
  resolution flow preview.
- `Bug_Tracking_4_Board_Workflow.gif` — issue movement across board columns.
- `Kanban_proj.pdf` and `Scrum_proj.pdf` — project workflow reports.

## Evidence note

Atlassian is installed, but this chat does not expose Jira actions or a live
browser session. The PNG and GIF files are **clearly marked Jira-style
mockups**, not screenshots or recordings from a real Jira workspace. Do not
submit them as live Jira evidence. To get genuine evidence, create the Jira
project, reproduce the records in `Bug_Reports.md`, and replace these previews
with captures from your Jira board.

Project represented in the previews: **Hyperlocal Courier Dispatch & Tracking
Engine** (suggested Jira key `HCDE`).
